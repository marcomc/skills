# Update AGENTS Workflows

Use this skill when the user asks to refresh `AGENTS.md` with newly discovered commands/workflows for any project type.

## Guardrails

- Keep edits minimal and scoped to workflow/command documentation.
- Ground every added command in repository evidence (config/docs/scripts), with source file+line.
- Do not edit unrelated sections or autogenerated files.
- If uncertain, add a TODO note instead of inventing behavior.

## Workflow

1. Run discovery in report mode:

```bash
~/.Codex/skills/update-agents-workflows/scripts/sync-agents-workflows.sh
```

1. Review candidates and uncertainty flags.
2. Apply conservative update only when requested:

```bash
~/.Codex/skills/update-agents-workflows/scripts/sync-agents-workflows.sh --apply
```

1. Summarize exactly what changed in `AGENTS.md` and why.

## Notes

- The script writes only to `AGENTS.md` and only within a managed TODO block.
- Existing AGENTS content is preserved.
- Re-running updates the managed block deterministically.
